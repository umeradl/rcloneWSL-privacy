# Privacy Policy — rcloneWSL

_Last updated: 2026-11-25_

rcloneWSL is a personal Google OAuth client for [rclone](https://rclone.org), used only by its owner.

- **What it accesses:** the owner's own Google Drive, to upload and manage the owner's own backup files.
- **What it collects:** nothing. No data is collected, stored on any server, sold, or shared with anyone.
- **Where data goes:** files move only between the owner's computer and the owner's Google Drive. The OAuth token stays in the local rclone config on the owner's computer.
- **Other users:** this app is not offered to anyone else.

Google user data is used in line with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
